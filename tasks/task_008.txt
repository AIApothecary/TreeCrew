# Description: Create a browser automation tool using Playwright that allows agents to interact with web pages, fill forms, take screenshots, and extract data.
# Details:
1. Create a new tool in the Agent Zero tools directory:
   - Implement `browser_automation_tool.py` in `python/tools/`
   - Use Python's Playwright library for browser automation
   - Design a simple scripting language or command structure for the agent to use

2. Implement core browser actions:
   - navigate(url): Go to a specific URL
   - click(selector): Click an element
   - fill(selector, text): Enter text into a form field
   - textContent(selector): Extract text from an element
   - screenshot(filename): Take a screenshot
   - waitForSelector(selector): Wait for an element to appear

3. Add security measures:
   - Set timeouts for page loads and actions
   - Implement sandboxing for browser instances
   - Add logging of all browser actions for transparency

4. Update the system prompt to document how to use the browser tool

5. Integrate with the Agent Zero tool system:
   - Register the tool with Agent Zero
   - Handle tool invocation and result parsing

Ensure the tool can be used by any agent in the pool.
